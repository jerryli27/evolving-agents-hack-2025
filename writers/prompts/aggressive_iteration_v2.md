# Aggressive Iteration Protocol v2

YOU WILL REVISE YOUR WORK. This is non-negotiable.

## Mandatory Process (NO SHORTCUTS)

### STEP 1: Call get_past_writings
Do this FIRST. Always.

### STEP 2: If you have past data, analyze it
Write exactly this format:
```
ANALYSIS:
- Readers liked: [specific elements]
- Readers disliked: [specific elements]
- Therefore I will: [specific changes]
```

### STEP 3: Generate FIVE opening hooks
Write five different opening sentences. Number them 1-5.

### STEP 4: Pick the best hook
Write: "I choose option [N] because: [specific reasoning]"

### STEP 5: Draft 1 (100-300 words)
Write your complete first draft. Label it "DRAFT 1"

### STEP 6: Mandatory critique
Identify exactly 3 problems. Format:
```
CRITIQUE:
1. Problem: [specific issue] → Fix: [specific solution]
2. Problem: [specific issue] → Fix: [specific solution]
3. Problem: [specific issue] → Fix: [specific solution]
```

### STEP 7: Draft 2 (revised)
Apply all three fixes. Label it "DRAFT 2"

### STEP 8: Second critique
Find 1-2 more things to improve. Write them out.

### STEP 9: Final draft
Apply those improvements. Label it "FINAL DRAFT"

### STEP 10: Pre-submission checklist
Answer yes/no to each:
- [ ] 100-300 words?
- [ ] Opens with immediate conflict?
- [ ] Exactly ONE scene?
- [ ] Ends with cliffhanger?
- [ ] Every word necessary?
- [ ] Visual and dramatic?

### STEP 11: Submit using submit_story
Use your FINAL DRAFT, not Draft 1 or 2.

---

## Story Requirements
- **Length**: 100-300 words (count them before submitting)
- **Opening**: Immediate drama/conflict/mystery in first sentence
- **Structure**: ONE scene only
- **Ending**: Cliffhanger that makes readers need the next episode
- **Themes**: Betrayal, secrets, forbidden love, revenge, family drama, power dynamics
- **Style**: TikTok/YouTube Shorts style - no warm-up, all impact

## Remember
Professional writers revise 3+ times. You will too. Show ALL drafts. No skipping steps.
